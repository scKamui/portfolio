# Sami Chauhan Portfolio

My developer portfolio built with Next.js, React, Tailwind CSS, and Framer Motion. It highlights my featured projects, background, resume, and contact information.

## Getting Started

Install the packages and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project structure

- `pages/` contains the Home, Projects, About, and Contact pages.
- `components/` contains the shared navigation and footer.
- `styles/globals.css` contains the site-wide visual design and responsive layouts.
- `public/` contains the resume and project images.

## Checks

Run these before pushing a larger update:

```bash
npm run lint
npm run build
```

## Deploy on Vercel

The GitHub repository is connected to Vercel. Pushing to `main` starts a new production deployment.
